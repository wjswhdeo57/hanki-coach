# 한끼코치 — 사진 칼로리 컨설팅 앱

사진을 찍으면 음식 이름·재료·양념 칼로리·양을 분석하고, 체중 감량/증가 목표에 맞춰
재료 빼기·더하기, 비슷한 맛의 대체 음식, 가벼운 레시피를 제안합니다.

- **AI 사용료 0원**: 음식 인식은 폰 브라우저 안에서 무료 모델(MobileCLIP-S0)로 처리. 외부 AI API 호출 없음.
- **사진 외부 전송 없음**, 기록은 폰 안에만 저장 (백업 파일로 이동 가능)
- 설치 없이 웹 주소로 열고 "홈 화면에 추가"하면 앱처럼 사용 (PWA)

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html / app.js | 앱 화면과 기능 |
| recognizer.js | 폰 안 음식 인식 (zero-shot + 한식 학습 헤드 + 개인 학습) |
| foods.js | 음식 영양 DB (data/part_*.json 병합본) |
| food-emb.json | 음식 설명 임베딩 (있으면 폰이 43MB 텍스트 모델을 받지 않아도 됨) |
| food-head.json | AI Hub 한식 사진으로 학습한 분류기 (trainer.html로 생성) |
| trainer.html | PC 브라우저용 한식 인식 학습기 |
| sw.js / manifest.webmanifest / icon-*.png | 오프라인 실행·홈 화면 아이콘 |

## 폰에서 쓰기
1. 폰 브라우저에서 `https://wjswhdeo57.github.io/hanki-coach/` 열기
2. 브라우저 메뉴 → "홈 화면에 추가" (아이폰 Safari: 공유 버튼 → 홈 화면에 추가)
3. 처음 사진 분석 때 AI 모델을 한 번 내려받아요 (와이파이 권장)

카메라·서비스워커는 https 주소에서만 동작합니다 (GitHub Pages는 기본 https).

## 인식 정확도 높이기
1. AI Hub 「한국 이미지(음식)」 신청·다운로드 → 압축 해제
2. 배포된 주소의 `trainer.html`을 PC Chrome에서 열기 → 데이터 폴더 선택 → 학습 시작
3. 생성된 `food-head.json`을 저장소에 업로드 → 폰 앱이 자동 적용

## 음식 DB
170종 (한식 밥·면·국·찌개·고기·반찬·분식, 중식·일식·아시안·양식·패스트푸드, 빵·디저트·음료·과일·간식).
1인분 수치는 식약처 식품영양성분 DB·외식 영양정보 수준의 일반적인 추정값입니다.
